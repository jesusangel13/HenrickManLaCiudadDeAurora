# Henrick Man: El Corazón de Aurora

Prototipo de aventura 3D para Windows, Capítulo 1: Ciudad Aurora. Proyecto académico relacionado con el ODS 7: Energía asequible y no contaminante.

## Abrir el proyecto

1. Descarga y extrae el archivo HenrickMan_CiudadAurora_UnitySource.zip.
2. En Unity Hub, agrega la carpeta UnityProject.
3. Usa Unity 6000.3.17f1 y abre Assets/HenrickMan/Scenes/CiudadAurora.unity.

El paquete contiene Assets, Packages, ProjectSettings y la documentación. No incluye cachés de Unity ni el ejecutable de Windows.

## Capítulo 1

Activa los tres relés con energía solar, eólica e hidráulica; cruza las islas flotantes, derrota al Guardián y restaura el Corazón de Aurora. Hay doble salto, esquiva, planeo eólico, checkpoints, una introducción ilustrada, pausa, opciones y créditos.

La interfaz muestra vida, energía, carga del modo Aurora, objetivo actual y salud del Guardián. Los capítulos Bosque de los Vientos, Templo de las Mareas y Fortaleza de Némesis siguen planificados.

## Controles

WASD mover; ratón cámara; Espacio saltar; Shift correr; C esquivar; Q cambiar poder; clic izquierdo atacar; clic derecho usar habilidad o planear con energía eólica; E activar; R modo Aurora; Escape pausar.
